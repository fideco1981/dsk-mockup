## Agent skills

### Issue tracker

Local markdown in `issues/`: one PRD plus numbered tickets, with finished ones moved to `issues/done/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default roles, written as a `Status:` line in each ticket. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
